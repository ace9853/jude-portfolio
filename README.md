# Jude Accanes — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally

1. Unzip the project folder if needed.
2. Open the `jude-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Before publishing

- Confirm that the internship description accurately reflects your work.
- Add links to your GitHub and LinkedIn profiles if you want them displayed.
- Replace planned project cards only when those projects are actually built.
- Add project screenshots and live links as projects are completed.

## Files

- `index.html` — page content and structure
- `style.css` — layout, colors, responsive design and animations
- `script.js` — mobile navigation, footer year and scroll reveals
